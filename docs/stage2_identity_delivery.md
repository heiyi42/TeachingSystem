# 第二阶段交付记录

日期：2026 年 10 月 1 日。范围为固定三课程的身份、班级权限、题目审核发布和版本绑定，前后端同步接入。作业、测验、完整教师学情报告和判分争议处理属于后续阶段。按用户要求，旧版页面入口、`/legacy` 路由及旧 Flask 页面模板已经移除，仅保留当前 React 界面。

## 已接入的流程

| 事项 | 当前行为 |
|---|---|
| 账号 | 首次在服务器本机初始化管理员；管理员创建教师账号；学生自行注册。注册请求不能自行指定教师或管理员角色 |
| 登录与退出 | 密码使用哈希保存，会话令牌只存摘要；Cookie 设置 HttpOnly、SameSite；登录限制、退出失效、改密码撤销全部会话已接入 |
| 学生记录 | 每次训练和聊天绑定账号。读取、保存、提交、提示、解析、复测及聊天事件均检查归属；账号切换清理页面缓存，浏览器草稿按账号分开 |
| 班级 | 教师创建本人的三课程班级；学生凭加入码加入；教师查看成员、更新加入码、移出成员 |
| 班级练习 | 学生开始时选择个人或所属班级；题目须属于班级课程；复测沿用原归属。移出班级后保留学生自身历史读取，拒绝继续向该班记录作答 |
| 教师证据 | 教师只能查看本人班级内当前成员的班级记录。只读查看当前草稿、首次错因、提示及解析使用、每次提交快照和核验结果；不能代学生提交 |
| 题库 | 67 道训练定义和 107 条规范问答题导入为草稿，保留来源、编辑者、审核者、依据和操作时间；未自动生成教师审核结论 |
| 审核发布 | 草稿可编辑并审核通过或退回；审核通过后再发布；已发布内容可撤下。已审核内容不能原地编辑，修订须建立新草稿版本 |
| 版本 | 学生只开始已发布训练；教师可预览草稿。发布修订自动撤下旧发布版本，已有练习保持开始时的题目快照及版本号，不随目录更新 |
| 问答参考题 | 规范题匹配只使用已发布版本，保留规范编号、旧编号别名及版本；修订题干或知识点后，旧向量文本不匹配时跳过旧向量 |

训练编辑当前支持标题与来源修订。题目参数、代码、过程规则和判分器仍由受控训练模板维护，修改时须同步开发和回归验证。问答编辑支持题干、参考答案、步骤、易错点、适用条件、知识点和来源。评分规则当前固定为 `rules-v1`，版本号用于记录依据；本阶段没有加入多套历史判分器运行机制。

## 使用顺序

1. 打开 `http://127.0.0.1:7860`，设置管理员用户名、姓名和密码，没有默认密码。
2. 管理员进入“班级与题库 → 账号设置”创建教师账号。教师登录后可改密码，再创建对应课程班级。
3. 教师进入“题库审核”，核查条件、参考过程和辅助内容，填写依据并审核，再填写发布依据发布。自动化测试不能代替教师实际复核。
4. 学生注册，进入“班级与题库”填写教师提供的加入码，在训练中心选择记录归属并开始已发布题目。
5. 教师从班级成员进入学生班级记录，查看作答及提交证据。

匿名训练演示继续可用，存储和正式记录分开。没有发布题目的课程显示暂无开放训练，不能把已有草稿数量当作正式可用题数。

## 数据与旧记录

身份和审核数据保存在训练数据库旁的 `<训练库文件名>_school.sqlite3`；默认对应 `data/learning_school.sqlite3`。原训练库继续使用 `data/learning.sqlite3`，不另建一套学习生命周期。

没有账号归属的旧版记录仅管理员可读，并标注旧版共享记录，不猜测历史学生身份。旧记录补充题目快照时，先创建 `<训练库文件名>_pre_identity.sqlite3` 备份；不改提交内容、核验结果或作答时间。已有快照则保持不变。旧聊天也仅管理员可访问。

正式数据库没有创建测试账号、班级或审核发布记录。本次浏览器流程使用 `tmp/stage2-browser.sqlite3` 及同目录的独立身份和聊天存储。

## 验收

- 全项目 155 项自动化检查通过，包含新增 8 项身份、权限、班级、发布版本、旧记录及会话检查；前端 TypeScript 检查和生产构建通过。构建保留原有体积及浏览器兼容数据提示。
- 越权检查覆盖匿名请求、注册角色提权、不同学生互读与修改、教师跨班访问、班级报告泄露个人练习、聊天操作和事件流；检查移出成员、旧加入码、跨课程练习及复测改归属。
- 会话检查覆盖密码哈希、Cookie 属性、令牌摘要、退出失效、改密码撤销所有会话、登录失败限制和跨来源修改拒绝。
- 内容检查覆盖未发布拒绝开始、审核状态跳跃、空依据、不可编辑已审核版本、训练模板篡改拒绝、空问答题干、问答草稿不泄露、修订后旧向量失效。
- 版本检查验证 v1 开始的练习在 v2 发布后仍使用 v1 条件完成核验；撤下后不再允许新建该题练习，已有记录可读取。旧记录迁移保留提交快照及时间并生成备份。
- 浏览器完成管理员建教师、教师建班与模拟审核发布、学生注册加入、班级练习保存刷新、首错提交和订正、教师只读证据；另检查发布修订版后学生旧记录仍显示原题和 v1，以及 390 像素手机布局、退出入口和整页宽度。截图及数据核对文件位于 `output/playwright/stage2-*`。
