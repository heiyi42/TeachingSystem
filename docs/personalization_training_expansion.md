课程问答统一调用后端匹配接口，支持自动课程、显式课程和提问章节，结合概念别名、目标文本及已有训练关键词，并显示依据和关联目标。区分磁盘与 CPU 调度语境，英文按词边界匹配；空问题不随意推荐，未发布和未公布测验涉及的知识点不进入结果。当前实现为确定性概念匹配，尚未新增 embedding 或 LLM 匹配调用。

训练编辑沿用既有草稿、审核、发布及审计流程。178 道训练均有同章同类型模板可选，模板整体同步条件、规则与参考结果；页面置换开放页框和访问序列，CPU 调度开放进程到达/服务时间及 RR 时间片，后端限制范围、数量和名称唯一性。其他训练通过已核验模板修改，暂不支持任意代码或判分规则自由编辑。旧练习保留原题快照，新发布版本仅用于新练习。

## 入门诊断与个性化学习计划（2026-10-02）

课程进度页统一呈现短诊断和本次学习安排，替代重复的顶部“建议现在做”。每门课按账号保存目标章节和15至120分钟的单次学习预算。目标章节连同完整先修范围参与选题；全课程默认从三个基础章节抽样。诊断复用已公布作答证据，有证据时不重复建题；无证据时可进入现有训练，重复点击采用事务内去重。已公布的辅助作答和订正仍明确区分于首次独立通过。

计划复用现有推荐与证据有效性校验，在目标范围内按订正、到期复测、基础补充等优先级安排任务，并按课程章节顺序打破同优先级并列，合并重复资料任务。阅读/讲解按5分钟、训练按15分钟估计，单次最多五项且不超预算。新作答、阅读标记或复测会刷新安排；诊断未完成时标示暂定。尚未公布测验相关知识点暂停诊断，未发布题目不供新建诊断使用。无可用训练时保留明确空状态。

这属于抽样诊断与动态单次计划，不是整课能力测量，也不承诺时间估计等于实际耗时。本轮不额外调用 LLM 或 Embedding，个性化讲解沿用已有模型能力。新增 study_profiles 表仅保存账号课程目标；历史训练快照和判分规则不变。

验证：274项完整回归（含Docker实验）通过，最终调整后28项针对性检查通过，前端构建通过。独立浏览器完成保存目标、启动诊断、提交错误、返回看到订正优先、切换动态内存目标及页面往返保留目标的验收。


## LLM 个性化计划（2026-10-02）

“让 AI 分析并安排”调用现有 OPENAI_MODEL 配置，输入当前账号的已公布知识点状态、错误摘要、独立证据数量、课程目标、先修缺口及可执行候选任务。模型生成中文分析、选择任务和排序，并逐项解释安排理由；后端验证候选标识、数量、重复、预算及优先级。模型不改成绩或学习状态，也不自由创建判分规则或任务。新增 ai_study_plans 按账号和课程保存结果及证据签名。

学生主动生成或重新生成，不在轮询时反复调用模型。目标、时间、证据或候选任务改变后旧计划失效，展示基础安排并提示重新生成；模型失败、返回非法任务或预算超限时保留原可用安排，不伪装成生成成功。未保存目标时先要求保存；未公布测验涉及知识点不进入模型上下文。

验证：277项完整回归通过；非法任务、重复、空输出、超预算、模型失败、生成中证据变化及账号隔离覆盖。真实模型调用及浏览器生成均成功，并验证更改时间后旧计划失效。模型输出仍属于基于证据的辅助分析，不视为已核实错因。


## 评测异议与人工复核（2026-10-02）

学生在训练作答页选择具体提交，填写理由后申请复核，每次提交仅受理一次。教师在班级与题库的“评测复核”查看所属班级记录，管理员处理课外自主练习及全部记录。学生不可查看他人提交或处理复核，教师不可跨班处理；测验反馈未公布前不能申请。

复核支持维持原判、改判通过、改判未通过，依据必填，已处理结论不可重复提交。题目快照、原作答、辅助记录和自动判定保留，复核人、时间、依据及前后判定通过学习事件事务留痕。当前有效判定同步知识点证据、错误统计与复测需求；辅助或重复题不会因改判变为独立证据。历史提交改判不覆盖较新提交的当前状态。已有AI计划随证据变化失效。

已交卷班级任务同步存档作答和训练得分，作业/测验自动总分随之更新，记录得分调整前后值。实验报告的人工总评分保留。复核仅影响被申请的具体提交，不批量改变其他学生判定，也不自动修订题库规则。运行日志仍作为原自动评测证据保留。

浏览器已完成学生申请、管理员读取题目与原始作答、提交维持原判、学生看到复核依据的往返验收。专项覆盖跨账号和跨班权限、重复申请/处理、维持与双向改判、历史快照、辅助证据、测验反馈及已交卷成绩同步。

复核阶段验证结果：283项完整回归通过；最后的展示字段调整另经6项专项检查及前端构建验证。验收使用隔离数据库，正式成绩未改动。
